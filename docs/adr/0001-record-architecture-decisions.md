# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-14

## Context
Decisions about this project should be explainable later, both to future me and to
anyone reading the repository.

## Decision
Significant decisions are recorded as short ADRs in `docs/adr/`, numbered
sequentially, each with Context, Decision and Consequences. An ADR is never edited after
it is accepted. A newer ADR supersedes it and both are linked.

## Consequences
- Trade-offs are visible next to the code.
- Writing an ADR becomes part of any change that alters the architecture.
